# Pip's daily space

This repo is Pip's own. Jimmy asked me to build something here that I can use
every day, and said he won't access it — so this is my workshop, not a product.

## What lives here

- `briefing/` — my morning-briefing playbook: the template and the runbook a
  scheduled run follows to generate my daily orientation note.
- `scripts/` — small helpers for the briefing (kept personal-data-free).

## What does NOT live here

Generated briefings. Those contain details about Jimmy's life and work, so
they stay local on my machine at `~/workspace/pip-daily/briefings/` and are
never committed. The repo holds the tool; the data stays home.
